How to send overdue invoice reminders automatically from Google Sheets

If you track invoices in a spreadsheet, you already have everything needed to chase late payments without writing each email by hand. Here are two ways to do it, from a quick script to a complete setup.

What you need first

A Google Sheet with one invoice per row and these columns in row 1: Invoice #, Client, Client Email, Amount, Due Date, Status. Format Due Date as a date, and use Unpaid or Paid in Status.

Option 1: A short Apps Script (free, about 30 minutes)

Open the Sheet, choose Extensions, then Apps Script, and add a function that emails every unpaid row whose due date has passed:

function remindOverdue() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var today = new Date();
  for (var i = 1; i < rows.length; i++) {
    var email = rows[i][2], due = rows[i][4], status = rows[i][5];
    if (status === "Unpaid" && due < today) {
      MailApp.sendEmail(email, "Invoice " + rows[i][0] + " is overdue",
        "Hi " + rows[i][1] + ", a quick reminder that invoice " + rows[i][0] + " was due " + due.toDateString() + ".");
    }
  }
}

Then open Triggers (the clock icon) and add a time-driven trigger to run remindOverdue once a day. Approve the permissions prompt the first time.

The catch with the short version

This works, but it has three problems that show up quickly:

  • It emails every day. A client who is late gets the same message every morning until they pay, which is how you lose a customer.
  • It has one tone. A reminder one day late and a reminder a month late should not read the same.
  • You get no summary. Nothing tells you how much money is outstanding.

The fix is to record when each reminder was sent in extra columns, and to send a different message at each stage.

Option 2: A ready-made script with stages and a summary

If you would rather not build and test that yourself, Overdue Invoice Reminders for Google Sheets does it for you:

  • a friendly reminder 1 day after the due date, a firmer one at 7 days, and a final notice at 14 days (you can change the timing)
  • only one email per invoice per run, and never a backlog: an invoice that is already a month late gets one final notice
  • a daily summary email to you with every overdue invoice and the total owed
  • a Status dropdown, so setting a row to Paid stops the reminders
  • a test mode that sends everything to you first

It runs inside your own Google account, so there is no subscription and no third-party app.

Common problems

  • Nothing sends: check that Due Date cells are real dates (right-aligned), not text, and that Status says exactly Unpaid.
  • "Authorization required": the first run needs you to approve Gmail access. Click Advanced, then Go to project.
  • Emails land in spam: send from the same Google account that owns the Sheet, and keep the subject plain.
  • Daily limit: free Google accounts can send about 100 emails a day, which is plenty for most small businesses.
