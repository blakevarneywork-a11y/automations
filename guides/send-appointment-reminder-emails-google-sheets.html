How to send automatic appointment reminder emails from Google Sheets

If you run a salon, clinic, tutoring practice or any business that works by appointment, a forgotten booking is an empty chair and lost income. A reminder email a day or two ahead fixes most of it. You can do this for free with a Google Sheet and a short Apps Script.

What you need

  • A Google account
  • A Google Sheet with one booking per row and these columns: Client, Client Email, Service, Appointment, Status
  • The Appointment column formatted as a date and time (Format, Number, Date time)

Step 1: Open the script editor

In the Sheet, click Extensions, then Apps Script. Delete the sample code in the editor.

Step 2: Add the reminder function

Paste this in. It emails anyone whose appointment is less than 48 hours away and whose Status is Booked:

function sendReminders() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var now = new Date();
  for (var i = 1; i < rows.length; i++) {
    var name = rows[i][0], email = rows[i][1], service = rows[i][2];
    var when = rows[i][3], status = rows[i][4], sent = rows[i][5];
    var hoursAway = (when - now) / 3600000;
    if (status === "Booked" && !sent && hoursAway > 0 && hoursAway <= 48) {
      MailApp.sendEmail(email, "Reminder: " + service + " on " + when.toDateString(),
        "Hi " + name + ", this is a reminder of your " + service + " on " + when.toLocaleString() + ".");
      sheet.getRange(i + 1, 6).setValue(new Date());
    }
  }
}

Put the heading Reminder Sent in column F. The script writes the time there so nobody is emailed twice.

Step 3: Run it on a timer

Click the clock icon (Triggers), then Add Trigger. Choose sendReminders, Time-driven, Hour timer, every hour. Approve the permissions prompt the first time (click Advanced, then Go to project).

Test it first

Add a row with your own email and an appointment a few hours from now, then click Run once. Check that the email arrives and column F fills in. Delete the test row afterward.

Limits of the simple version

  • It sends one reminder only. A second reminder a few hours before the visit needs more logic.
  • A booking made at the last minute is treated the same as one made last week.
  • It reads columns by position, so moving a column breaks it.
  • Free Google accounts can send roughly 100 emails a day.

If you want two reminders per booking, a cancellation status that stops them, a test mode that sends everything to you, and column names you can change, that is the next step up from this script.

Common problems

  • No email arrives: check that the Appointment cell is a real date and not text. Left-aligned values are usually text.
  • Wrong time in the email: set your time zone under File, Settings in the Sheet.
  • "Authorization required": run the function once by hand and approve access.
