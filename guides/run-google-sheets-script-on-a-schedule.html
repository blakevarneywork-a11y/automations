How to run a Google Sheets script on a schedule (time-driven triggers)

An Apps Script that only runs when you open the Sheet and click a button is not much of an automation. A time-driven trigger makes it run by itself every day, every week, or every hour, even when the Sheet is closed.

Set up a trigger in the editor

  1. Open the Sheet, then choose Extensions, then Apps Script.
  2. Click the clock icon (Triggers) in the left sidebar.
  3. Click Add Trigger at the bottom right.
  4. Choose the function to run, set Event source to Time-driven, and pick the interval: minutes, hours, day, week or month.
  5. Save, and approve the permissions prompt the first time. Click Advanced, then Go to project.

Pick a time window for daily triggers (for example 8am to 9am). Google runs it at some point inside that hour, not at an exact minute.

Or create the trigger in code

If you want a script to install its own trigger, run this once:

function installDailyTrigger() {
  ScriptApp.newTrigger("myFunction")
    .timeBased()
    .everyDays(1)
    .atHour(8)
    .create();
}

Run it only once. Every run adds another trigger, and duplicates mean duplicate emails. To clean up, call ScriptApp.getProjectTriggers() and delete extras with ScriptApp.deleteTrigger(t).

Problems that catch people

  • It runs but nothing happens: open Executions in the sidebar and read the error. Most failures are a renamed sheet tab or a column that moved.
  • It stopped working after a while: the trigger belongs to the account that created it. If that account loses access to the Sheet, or you changed its password and the authorization expired, open the editor and re-approve.
  • Duplicate messages: you have two triggers on the same function. Check the Triggers list.
  • Time zone is wrong: set it under Project Settings in the Apps Script editor. It is separate from the spreadsheet's time zone.
  • Quota limits: free Google accounts can send about 100 emails a day and a script can run for about 6 minutes per execution. Stop early and carry on at the next run if you hit the limit.
